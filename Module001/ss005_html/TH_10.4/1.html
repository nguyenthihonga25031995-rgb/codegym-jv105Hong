Hướng dẫn cho người mới bắt đầu học HTML

  • Chuẩn bị
    1. Cài đặt trình soạn thảo (VS Code, Notepad++)
    2. Tạo file .html
    3. Mở file bằng trình duyệt
  • Học các thẻ cơ bản
    1. Thẻ tiêu đề (h1 → h6)
    2. Thẻ đoạn văn (p)
    3. Thẻ liên kết (a)
  • Luyện tập
    1. Viết trang web đơn giản
    2. Thử tạo danh sách với ul, ol, li
    3. Chỉnh sửa và xem kết quả
  • Nâng cao
    1. Học CSS để làm đẹp
    2. Học JavaScript để tạo tương tác
